# Avatar sources

Give each avatar its own folder. Put the original rigged body in `source/`, reference images in `references/`, and editable clothing scenes in `outfits/`. For example, an outfit might be saved as `avatars/MyAvatar/outfits/Jacket.blend`.

Blender, FBX, GLB, Photoshop and Unity package files under this directory use Git LFS. Install Git LFS before adding or downloading avatar files. Keep companion texture files next to an FBX or use Blender’s **File → External Data → Pack Resources** in an editable scene.

The repository is public. Files committed here can be downloaded. Local image references also work from any folder on your computer.
